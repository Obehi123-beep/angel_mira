# Angel Mira

Angel Mira is a responsive logistics and delivery services website built as a frontend development project.

The project was created to practice building professional business websites, responsive layouts, navigation, service sections, structured content, and user-friendly interfaces.

## Features

* Responsive logistics and delivery website
* Professional business website layout
* Logistics service information
* Delivery and shipping service sections
* Company information pages
* Responsive navigation
* Mobile-friendly design
* Structured service content
* Responsive images and visual sections

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap

## Live Website

[Visit Angel Mira](http://angelmira.obehiinnovatives.com.ng/)

## About the Project

Angel Mira was developed during my frontend development journey while learning how to build responsive business websites using HTML, CSS, JavaScript, and Bootstrap.

The project provided practical experience with responsive layouts, navigation, page structure, styling, images, business content, and frontend user interface development.
